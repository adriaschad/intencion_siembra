# Manual de Usuario - Sistema de Intención de Siembra v3

## Introducción

Bienvenido al Sistema de Intención de Siembra, una plataforma integral diseñada para gestionar y visualizar datos relacionados con las intenciones de siembra de productores agrícolas. Este sistema proporciona herramientas avanzadas de análisis mediante un dashboard interactivo que permite filtrar, analizar y exportar información clave para la toma de decisiones.

El presente manual tiene como objetivo guiar a los usuarios en el uso efectivo de todas las funcionalidades del sistema, desde el acceso inicial hasta la interpretación de datos complejos mediante gráficos y tablas dinámicas.

### Objetivos del sistema

- Centralizar la información de intenciones de siembra
- Facilitar el análisis de datos mediante visualizaciones interactivas
- Permitir la consulta eficiente de información histórica y actual
- Proporcionar indicadores clave de desempeño (KPIs) en tiempo real
- Ofrecer múltiples formatos de exportación de datos

## Requisitos y acceso

### Requisitos técnicos

Para utilizar el Sistema de Intención de Siembra, asegúrese de cumplir con los siguientes requisitos:

**Navegadores web compatibles:**
- Google Chrome (versión 90 o superior)
- Mozilla Firefox (versión 88 o superior)
- Microsoft Edge (versión 90 o superior)
- Safari (versión 14 o superior)

**Requisitos de sistema:**
- Conexión a Internet estable (mínimo 2 Mbps)
- Resolución de pantalla mínima: 1280x720 píxeles
- JavaScript habilitado en el navegador

**Para dispositivos móviles (APK Android):**
- Android 6.0 (Marshmallow) o superior
- Mínimo 100 MB de espacio libre
- Permisos de almacenamiento e Internet

### Obtención de credenciales

Para acceder al sistema, debe solicitar sus credenciales de acceso a través del administrador de su organización. Las credenciales incluyen:

- **Usuario:** Nombre de usuario único asignado
- **Contraseña:** Clave personal (se recomienda cambiarla en el primer acceso)

### URL de acceso

El sistema está disponible en la dirección web proporcionada por su organización. Guarde esta URL en sus marcadores para facilitar el acceso futuro.

## Iniciar sesión y cerrar sesión

### Proceso de inicio de sesión

1. Abra su navegador web e ingrese a la URL del sistema
2. En la pantalla de inicio, encontrará el formulario de autenticación
3. Ingrese su **nombre de usuario** en el campo correspondiente
4. Ingrese su **contraseña** (los caracteres se mostrarán ocultos por seguridad)
5. Haga clic en el botón **"Iniciar sesión"** o presione Enter

![Pantalla de inicio de sesión](images/image1.jpeg)
*Figura 1: Pantalla de inicio de sesión del sistema*

**Nota de seguridad:** Si ingresa credenciales incorrectas tres veces consecutivas, su cuenta se bloqueará temporalmente por razones de seguridad. Contacte al administrador si esto ocurre.

### Recuperación de contraseña

Si olvidó su contraseña:

1. En la pantalla de inicio de sesión, haga clic en "¿Olvidó su contraseña?"
2. Ingrese su nombre de usuario o correo electrónico registrado
3. Recibirá instrucciones para restablecer su contraseña
4. Siga el enlace recibido por correo electrónico
5. Establezca una nueva contraseña segura

### Cerrar sesión

Para cerrar sesión de manera segura:

1. Haga clic en su nombre de usuario en la esquina superior derecha
2. Seleccione la opción **"Cerrar sesión"** del menú desplegable
3. Será redirigido automáticamente a la pantalla de inicio de sesión

**Importante:** Siempre cierre sesión cuando termine de usar el sistema, especialmente en computadoras compartidas.

## App móvil (APK)

### Descarga e instalación

El sistema cuenta con una aplicación móvil para dispositivos Android que permite acceder a las funcionalidades principales desde cualquier lugar.

**Pasos para la instalación:**

1. Descargue el archivo APK desde el enlace proporcionado por su organización
2. En su dispositivo Android, vaya a **Configuración > Seguridad**
3. Active la opción **"Fuentes desconocidas"** o **"Instalar aplicaciones desconocidas"**
4. Abra el archivo APK descargado
5. Toque **"Instalar"** y espere a que finalice el proceso
6. Una vez instalada, encontrará el ícono de la aplicación en su pantalla de inicio

### Funcionalidades de la app móvil

La aplicación móvil incluye:

- Acceso completo al dashboard de visualización
- Consulta de datos en tiempo real
- Filtrado de información por múltiples criterios
- Visualización de gráficos y tablas
- Modo offline para consulta de datos previamente cargados

### Sincronización de datos

La aplicación sincroniza automáticamente los datos cuando hay conexión a Internet disponible. Para forzar una sincronización manual:

1. Deslice hacia abajo en la pantalla principal
2. Espere a que aparezca el indicador de actualización
3. Los datos se actualizarán automáticamente

### Filtros disponibles

El sistema ofrece múltiples opciones de filtrado para segmentar la información según sus necesidades.

#### Filtros principales

**Filtro por fecha:**
- Permite seleccionar un rango de fechas específico
- Opciones predefinidas: Hoy, Última semana, Último mes, Último año
- Selector personalizado para rangos específicos

**Filtro por región:**

- Visualización jerárquica: País > Provincia > Municipio
- Búsqueda rápida por nombre de ubicación

**Filtro por cultivo:**

**Filtro por productor:**

### Indicadores KPI

Los KPIs (Key Performance Indicators) proporcionan una visión rápida de las métricas más importantes.

**KPIs principales visualizados:**

1. **Total de hectáreas intención:** Suma total de hectáreas declaradas
2. **Número de productores:** Cantidad de productores registrados
3. **Cultivos registrados:** Número de tipos de cultivos diferentes
4. **Promedio hectáreas/productor:** Media de hectáreas por productor

- Gráfico de tendencia miniatura

## Ejemplos rápidos

### Ejemplo 1: Consultar hectáreas de soja en una región específica

1. En el panel de filtros, seleccione **"Cultivo"** → **"Soja"**
2. En **"Región"**, seleccione la provincia deseada
3. Haga clic en **"Aplicar filtros"**
4. El KPI de **"Total de hectáreas intención"** mostrará el resultado
5. Revise el gráfico de barras para ver distribución por municipio

### Ejemplo 2: Generar reporte mensual de intenciones

1. Configure el filtro de fecha: seleccione el mes completo deseado
2. Deje los demás filtros en blanco para incluir todos los datos
3. Revise los KPIs para obtener el resumen ejecutivo
4. Haga clic en **"Exportar"** → **"PDF"**
5. Active la opción **"Incluir gráficos"** y **"Incluir resumen"**
6. Descargue el reporte generado

### Ejemplo 3: Comparar cultivos entre dos períodos

1. Configure el filtro de fecha para el primer período (ej: enero-marzo 2024)
2. Tome nota de los valores de los KPIs
3. Cambie el filtro de fecha al segundo período (ej: abril-junio 2024)
4. Compare los valores y porcentajes de variación mostrados en los KPIs
5. Use el gráfico de líneas para visualizar la tendencia temporal completa

### Ejemplo 4: Identificar los principales productores

1. Vaya a la tabla de datos
2. Haga clic en el encabezado **"Hectáreas declaradas"** para ordenar descendente
3. Los primeros registros mostrarán los productores con mayor superficie
4. Puede exportar esta lista filtrada a Excel para análisis posterior

## Preguntas frecuentes (FAQ)

### ¿Qué hago si olvido mi contraseña?

Use la opción "¿Olvidó su contraseña?" en la pantalla de inicio de sesión. Recibirá un correo electrónico con instrucciones para restablecerla.

### ¿Los datos se actualizan en tiempo real?

Sí, el sistema se actualiza automáticamente cada vez que se registra nueva información. Puede forzar una actualización manual haciendo clic en el botón de actualización en la barra superior.

### ¿Puedo guardar mis filtros favoritos?

Actualmente, el sistema no guarda los filtros automáticamente. Se recomienda documentar las configuraciones de filtros más utilizadas para aplicarlas rápidamente cuando sea necesario.

### ¿Cuántos registros puedo exportar a la vez?

El sistema permite exportar hasta 100,000 registros en una sola operación. Para conjuntos de datos más grandes, se recomienda dividir la exportación usando filtros de fecha o región.

### ¿La aplicación móvil funciona sin conexión a Internet?

La aplicación puede mostrar datos previamente cargados sin conexión, pero no podrá actualizar información ni registrar nuevos datos sin conexión a Internet.

### ¿Cómo puedo reportar un error en el sistema?

Use la opción de "Soporte" en el menú principal o contacte directamente al equipo técnico usando los datos de contacto proporcionados en la sección de Soporte.

### ¿Puedo acceder al sistema desde múltiples dispositivos?

Sí, puede acceder desde cualquier dispositivo con sus credenciales. Sin embargo, solo se permite una sesión activa por usuario. Al iniciar sesión en un nuevo dispositivo, la sesión anterior se cerrará automáticamente.

### ¿Los gráficos se pueden personalizar?

Los gráficos tienen opciones de personalización limitadas (tipo de visualización, escala, etc.). Para análisis más detallados, se recomienda exportar los datos a Excel.

## Glosario

**APK:** Android Package Kit, formato de archivo para instalar aplicaciones en dispositivos Android.

**Dashboard:** Panel de control visual que muestra información clave mediante gráficos, tablas e indicadores.

**Filtro:** Herramienta que permite segmentar datos según criterios específicos.

**Hectárea:** Unidad de medida de superficie equivalente a 10,000 metros cuadrados.

**Intención de siembra:** Declaración anticipada del área y tipo de cultivo que un productor planea sembrar.

**KPI (Key Performance Indicator):** Indicador clave de desempeño que mide el rendimiento de un proceso específico.

**Exportación:** Proceso de guardar datos del sistema en un archivo externo en diversos formatos (Excel, PDF, CSV, etc.).

**Sesión:** Período de tiempo durante el cual un usuario permanece autenticado en el sistema.

**Tooltip:** Mensaje emergente que aparece al pasar el cursor sobre un elemento, mostrando información adicional.

**Zoom:** Acción de ampliar o reducir la vista de un gráfico para ver detalles específicos.

**Productor:** Persona o entidad dedicada a la actividad agrícola que registra intenciones de siembra.

**Rango de fechas:** Período de tiempo definido por una fecha de inicio y una fecha de fin.

**CSV (Comma-Separated Values):** Formato de archivo que almacena datos en texto plano separados por comas.

**Sincronización:** Proceso de actualización de datos entre el servidor y la aplicación cliente.
