# Intención de Siembra

Sistema de registro digital de boletas de siembra para productores agrícolas.

📚 **[Manual de Usuario v3](docs/Manual_Usuario_Intencion_Siembra_v3.md)** - Guía completa del sistema

## Características

- ✅ Registro digital de boletas de siembra
- ✅ Dashboard con KPIs y gráficos
- ✅ Modo offline con sincronización automática
- ✅ Aplicación móvil para Android (APK)
- ✅ Validación de datos en tiempo real
